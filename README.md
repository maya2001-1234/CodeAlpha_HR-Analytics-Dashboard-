HR Analytics Dashboard Using Power BI

 Project Overview

The HR Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI as part of my Power BI internship.

The main purpose of this project is to analyze employee information and provide useful insights into workforce management, employee attrition, recruitment sources, employee performance, and satisfaction.

The dashboard presents important HR metrics through interactive visualizations, charts, and Key Performance Indicators (KPIs), helping users understand workforce patterns and support data-driven decision-making.

 Project Objectives

- Analyze employee distribution across departments and job roles.
- Monitor employee employment status and termination patterns.
- Explore historical hiring trends and recruitment sources.
- Analyze employee satisfaction and performance.
- Present important HR metrics using interactive dashboards.
- Support HR analysis and decision-making through data visualization.

 Dashboard Pages

The Power BI report consists of three main pages.

 1. HR Overview

Provides an overall summary of the organization's workforce.

Key Metrics and Visualizations:

- Total Employees
- Active Employees
- Employees Terminated
- Terminated Share of Records
- Employee distribution by department
- Employment status analysis
- Performance score by department

 2. Attrition and Termination Analysis

Focuses on employee termination patterns and historical workforce changes.

Key Visualizations:

- Terminated employees by department
- Termination reasons analysis
- Employee terminations by year
- Department-wise employee and termination comparisons
- Interactive filters for exploring termination information

 3. Hiring Sources and Workforce Experience

Explores recruitment sources and different aspects of employee experience.

Key Visualizations:

- Employee records by recruitment source
- Employee hiring trends by year
- Average employee satisfaction by department
- Employee performance comparisons
- Average engagement score
- Average satisfaction score
- Average employee absences

 Dataset Description

The project uses an HR employee dataset containing employee-related information.

The dataset includes information such as:

- Employee identification
- Department and job position
- Employment status
- Hire and termination dates
- Salary information
- Recruitment sources
- Employee performance scores
- Employee satisfaction and engagement
- Absences and lateness
- Termination reasons

The dataset was prepared and analyzed using Power Query and Microsoft Power BI.

 Data Analysis and Limitations

The dashboard focuses on historical employee information available in the supplied dataset.

The Terminated Share of Records represents the percentage of employee records marked as terminated out of all employee records. It should not be interpreted as an annual employee turnover rate.

The dataset does not contain complete applicant-level recruitment information, such as total applicants and rejected applications. Therefore, a complete recruitment conversion funnel cannot be calculated.

Reliable future hiring forecasts would also require additional information, such as planned workforce requirements and future vacancies.

 How to Use the Project

1. Download or clone this repository.
2. Open the `PowerBI` folder.
3. Open `HR_Analytics_Dashboard.pbix` using Microsoft Power BI Desktop.
4. If Power BI requests the source dataset, select an authorized copy of the HR Excel file and update the data source path if necessary.
5. Refresh the data if required.
6. Navigate through the three dashboard pages.
7. Use the available slicers and filters to explore the HR information.

Note: Microsoft Power BI Desktop is required to open and interact with the `.pbix` report. The original employee dataset is not included in the public repository.
